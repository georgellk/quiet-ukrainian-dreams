# Ukrainian Dream Bedding

Create a high-end, mobile-first e-commerce single-page website for a premium Ukrainian bedding brand. The primary target audience is mobile users, so prioritize an ultra-responsive, thumb-friendly, sleek layout with smooth scroll animations. 

Apply a premium "Quiet Luxury" aesthetic combined with modern dynamic background shifts to visually separate product categories as the user scrolls.

### 1. Brand Identity & Design System:

- Typography: Elegant editorial serif for headings (e.g., Playfair Display or Cormorant), clean geometric sans-serif for body text.

- Navigation: Minimalist floating bottom bar or top sticky bar optimized for mobile thumbs.

- Visual FX: Smooth CSS background-color transitions (transition: background 0.6s ease) when transitioning between product blocks. Glassmorphism cards with subtle inner borders.

### 2. Main Hero Section (Affordable Luxury & Strong Ukrainian Offer):

- Background: Deep rich ivory/cream clean canvas.

- Main Headline (UA): "ЛІКВІДАЦІЯ СКЛАДУ УКРАЇНСЬКОГО ВИРОБНИКА"

- Sub-headline/Offer (UA): "Преміальна якість натуральних тканин зі знижками до -55%. Підтримай українське — інвестуй у здоровий сон."

- Visual: Cinematic macro close-up of premium stitching and natural fabric textures. A subtle, elegant minimalist badge or elegant timer "Акція обмежена".

- CTA Button: "Обрати свій комфорт" (Smooth scrolling to categories).

### 3. "Oversized Dynamic Scrolling" Product Catalog:

The catalog must change backgrounds gracefully based on the active category to immerse the user into the specific filler material.

#### CATEGORY A: PREMIUM BLANKETS (4 Types)

- Section Background: Smoothly transitions into Warm Sand / Terracotta tones when scrolling into Camel Wool.

- Item 1: Ковдра "Верблюжа вовна" (TOP SELLER / Хіт Продажів). Highlight with a subtle golden border or "Топ вибір" tag. Focus on thermal regulation and luxury warmth.

- Item 2: Ковдра "Овеча вовна". Soft Cream / Ivory micro-section background. Focus on classic alpine cozy comfort.

- Item 3: Ковдра "Бамбукове волокно". Soft muted sage green/mint white accent. Focus on eco-friendly, hypoallergenic freshness.

- Item 4: Ковдра "Лебединий еко-пух". Pure cloud-white airy accent. Focus on ultimate weightless hotel-luxury softness.

#### CATEGORY B: COMFORT PILLOWS (3 Types)

- Section Background: Smoothly transitions into Light Airy Minimalist Grey/White shades.

- Layout: 2-column clean grid on desktop, single-card swipeable slider or clean vertical stack on mobile.

- Item 1: Набір подушок "Верблюжа вовна" (Premium Support).

- Item 2: Набір подушок "Овеча вовна" (Cozy Comfort).

- Item 3: Набір подушок "Лебединий еко-пух" (Cloud Softness).

### 4. E-commerce Card UI Mechanics (Optimized for Mobile Conversion):

- Every product card must show a clear contrast between the old crossed-out price (Premium tier) and the current liquidation price (-55%).

- Size selectors must be large, finger-tappable buttons (e.g., 150х210, 175х210, 200х220) instead of tiny dropdowns.

- Quick Checkout CTA: "Замовити зі знижкою" opens a sleek, non-intrusive 2-input bottom sheet modal (Name, Phone) with a note "Вибір розміру уточнимо під час дзвінка з менеджером".

### 5. Trust & Footprint Block:

- Quick visual badges: "Швидка доставка Новою Поштою (1-2 дні)", "Оплата при отриманні (Післяплата)", "14 днів на обмін та повернення".

- Clean customer reviews slider with text and ratings.

- Footer featuring the brand signature "Теплі ковдри та подушки нового покоління. Вироблено з гордістю в Україні."
